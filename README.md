# MarzzDraw
Game gambar & tebak kata multiplayer. Tanpa dependensi.

## Jalankan
    node server.js
Buka http://localhost:3000 di beberapa tab/perangkat untuk mencoba multiplayer.

## Online
Deploy ke hosting Node.js (Render, Railway, Fly.io, VPS). Perintah start: `node server.js` (port dari env PORT).
